# Project Lab

A collection of interactive web projects built with **HTML, CSS, and JavaScript**, developed as part of my **GSSoC'26 contributions**. These projects focus on practical frontend development, interactive UI design, JavaScript logic, and problem-solving.

## 🚀 Projects

### 1. Compiler Workflow Visualizer
An interactive web-based visualization of the different stages involved in a compiler workflow.

**Highlights:**
- Interactive compiler workflow
- Visual representation of compilation stages
- Clean and intuitive interface
- Built using HTML, CSS, and JavaScript

### 2. Kanban Board
A simple and interactive task management application for organizing tasks across different stages.

**Highlights:**
- Create and manage tasks
- Organize tasks using different columns
- Interactive task management
- Responsive user interface

### 3. Flashcard Learning App
An interactive learning application designed to help users create, review, and manage flashcards.

**Highlights:**
- Interactive flashcards
- Easy learning and revision
- JavaScript-based interactions
- User-friendly interface

### 4. Sudoku Generator
A browser-based Sudoku generator that uses JavaScript logic and algorithms to generate Sudoku puzzles.

**Highlights:**
- Automatic Sudoku generation
- Interactive puzzle interface
- Algorithm-based puzzle creation
- Responsive design

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **DOM Manipulation**
- **Local Storage**
- **Responsive Web Design**

## 💻 Getting Started

### 1. Clone the repository
```bash
git clone [https://github.com/your-username/Project-Lab.git](https://github.com/your-username/Project-Lab.git)
```

### 💻 Launching a Project

Navigate to the root directory:

```bash
cd Project-Lab
```
Open any project folder and launch the index.html file in your web browser. For example:
```bash
compiler-workflow-visualizer/index.html
```

Note: No additional dependencies, node modules, or installations are required.
